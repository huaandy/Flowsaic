# Flowsaic frontend — extracted from Figma Make

Source: Interactive Frontend Prototype.make (embedded repository commit 018dbab8203476c42def9e583c3226cb7428c8da).

## Import into your team repository
1. Create a feature branch in your existing team repo.
2. Copy the contents of `flowsaic-frontend/` into the repository's `frontend/` directory (or your existing frontend location).
3. Review changes before overwriting existing files.
4. Run `npm install` and `npm run dev` from the frontend directory.
5. Commit and push your branch; open a pull request.

This is an exported Figma Make prototype, not a production-ready university-integrated application. Review simulated data and account behavior before deployment.

The Vite config was retained from Figma Make and includes Figma-specific helpers. The `.figma/make/site.json` file is included because the config imports it.
